# 06 · QA checklist (run on each thumbnail before it ships)

## Concept
- [ ] I can state the video in ≤10 words.
- [ ] I named the lever: MIEDO / INTRIGA / DESEO.
- [ ] The text **doesn't repeat** the title it's paired with, or the alternates. It adds a new angle or question.
- [ ] **Cover test:** it works with no title; the title works with no thumbnail.
- [ ] The 3 thumbnails of the video make 3 different promises.
- [ ] The **first 5 seconds** of the video visibly confirm the promise. If not, flag it on the page.

## Text
- [ ] 2-4 words, ALL CAPS, two lines (yellow / white).
- [ ] Correct Spanish: accents, ¿ ¡, no typos. (The reference page has a typo in its title, "archivadon". Don't copy typos.)
- [ ] It starts from a ★ formula in the bank (04), or has a reason not to.
- [ ] Red only on ¿ ? (or "No red text").
- [ ] It passes the legal check (05).

## Image
- [ ] One face, large, cut out, rim-lit, with a readable emotion that matches the lever.
- [ ] One faint context object, at most.
- [ ] The text sits in open space on the opposite side from the face.
- [ ] 2-3 dominant colours; it passes the grayscale test and the phone-size test.
- [ ] No date, no logo, no extra text.

## Page (Notion, Actions2.5)
- [ ] "## Miniaturas" with: Recomendado + one "Promesa: … · [alternate title]" per alternate.
- [ ] Under each: "Sujeto: [person], usa una foto de [person]" + a code block with the prompt in English.
- [ ] No reasoning, scores or notes on the page. It's a deliverable, not a log.
- [ ] For Test & Compare: main title + first 2 alternates, each with its own thumbnail. Record it in the Results log.
