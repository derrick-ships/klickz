# OpenPikzels Gestures Implementation Plan
> For agentic workers: use superpowers:executing-plans; native implementation followed by one fresh final review.
**Goal:** Add direct, accessible image gestures inside the existing studio.
**Architecture:** Focused inspection component, pointer-driven comparison and native-scroll revision controls. DOM transforms during tracking; state updates only at boundaries/release. No dependencies, credentials or database changes.
**Tech Stack:** React19, TypeScript, native Pointer Events, ResizeObserver and browser scroll.
**Spec:** docs/superpowers/specs/2026-11-08-gestures-design.md

## Global Constraints
Preserve page zoom and vertical scroll at fit. Keep native slider keyboard support, visible controls,44px targets and reduced motion. Never trigger AI or deletion through gestures. No persistent cloud install claim.

## Review Focus
1. A canceled drag or second pointer must not jump or activate an image.
2. Image pan bounds must account for letterboxing and changing viewport dimensions.
3. Browser/page zoom stays available, including Ctrl/Cmd wheel.
4. Gesture release/close/source changes clean up all captures and animation frames.
5. Horizontal history scrolling must retain ordinary activation and keyboard focus.
