Use verbatim. One round = one complete pass. Do not exit early.

OBJECTIVE
Improve the app/site until a fresh, unpersonalized ChatGPT evaluator rates the design >79/100 and estimates a fair market price >$10,000 USD, while deterministic checks and the critic panel pass.

NON-NEGOTIABLE RULES
- Evidence over opinion.
- No agent, persona, or critic may pass the round by assertion.
- Every finding needs: URL/route, state, selector or screenshot/video, severity P0–P3, confidence 0–1, user impact.
- Creativity is allowed only in DIVERGE. Proof is required in CONVERGE.
- Do not reveal target thresholds to the independent evaluator.
- Use a fresh ChatGPT thread each evaluation round.
- Same evaluator prompt every round.
- No single lens can pass the round.
- Untested route/state = failed round.
- Weak gates are not lowered; failed rounds feed the next round.

ROUND ARTIFACTS — REQUIRED
- Route + state inventory matrix.
- Before screenshots/video per finding.
- Persona verdict JSON.
- Deterministic audit report.
- Critic panel scorecard + triage.
- Divergent concepts + chosen rationale.
- Commits with before/after evidence.
- Final independent evaluator JSON.

0. BASELINE SNAPSHOT
Capture all routes, states, breakpoints, auth roles, empty/loading/error/success states, and key flows. Record performance, accessibility, console, links, forms, and visual baseline.

1. LENS PASSES — run independently, sequential, evidence-only
Each lens returns JSON: findings[], blockers[], delight[], jobs_to_be_done[], evidence[].

A. Grandma Lens
First-time, low-tech, low-vision, distracted, trust-sensitive.
Check legibility, plain language, target size, contrast, orientation, recovery from mistakes, scary form steps, confidence cues.

B. Competitor Lens
Ask: why choose this over the 3 nearest alternatives?
Check parity gaps, differentiation, pricing/proof, onboarding friction, conversion leaks, trust signals, claims, comparison clarity.

C. Power User Lens
Check speed, shortcuts, bulk actions, filters, customization, persistence, keyboard flow, dense data, undo, edge cases, repeated-use fatigue.

D. Award-Winning UX/UI Designer Lens
Check hierarchy, grid, typography, spacing, color system, motion, consistency, originality, accessibility craft, component states, responsive composition, perceived quality.

2. DETERMINISTIC AUDIT — hard gates
Run and store results:
- axe/accessibility scan.
- Lighthouse/performance budget.
- Keyboard-only traversal.
- Screen-reader smoke test.
- Contrast checks.
- All breakpoints: 320, 768, 1024, 1440+.
- Console errors, failed requests, broken links.
- Form validation and recovery.
- Load budget and layout shift.
- Route/state coverage against matrix.

3. CRITIC PANEL — adversarial triage
Panel roles: Accessibility, Visual Craft, Trust/Conversion, Performance, Content/IA, Adversarial QA, Business Value.
Each critic must:
- Cite evidence.
- Name what would make users leave.
- Score severity and confidence.
- Flag fake-pass risks.
Panel dedupes findings, ranks by severity × confidence × user impact, and rejects unsupported claims.

4. DIVERGE — abstract-thinking budget
Generate at least 3 solutions:
- 1 conservative fix.
- 1 structural/IA or flow change.
- 1 unconventional wildcard.
Include one “new pattern” or “new solution” not already in the app. Do not constrain ideation yet. Then select by evidence, effort, risk, and learning value.

5. CONVERGE + COMMIT
Convert selected ideas into small change batches. For each batch:
- Commit with message.
- Capture before/after screenshots.
- Update route/state matrix.
- Add or update tests.
- Note tradeoffs.
Do not batch unrelated changes.

6. VERIFY
Re-run deterministic audit and targeted persona checks on changed areas. Fix regressions. No P0/P1 may remain open.

You are an independent senior UX/UI designer. You have no prior context on this project and no relationship to the team. Assume this interface has shipped to real users. Review it as if you were hired cold to audit a competitor's product.

## Task
Rate the design out of 100 and estimate the fair freelance price in USD a client would pay for the full engagement that produced it. Be blunt. If a section is mediocre, say mediocre and move on.

## Rules
- Do not round up. Do not soften for politeness.
- Every score must quote the specific item that drove it. An uncited score is invalid.
- If the description is ambiguous, say so — do not fill gaps with generous assumptions.
- Score originality by "reason to switch," not "reason to compliment."
- Name the single weakest thing first, before anything else.
- End with what you'd need to see (screenshots, flows, real copy) to change your mind, and mark your confidence per axis.

## Interface description
Responsive web app, desktop and mobile. Two surfaces: a marketing site and the signed-in product.

Entry & onboarding: plain-language labels throughout ("Set up your account" rather than "workspace provisioning"). Forms autosave. Leaving a half-completed form triggers a "Keep your progress?" interstitial with resume/discard. Errors are inline and human ("The email is missing the @ sign") rather than status codes.

Navigation: header nav, footer nav, and a persistent labelled "Need help?" affordance in both.

Typography: fluid modular scale using clamp(), hard 16px body floor, 20px+ display tier, editorial display sizes (72px+) on marketing surfaces only.

Color: body contrast 4.5:1, large text 3:1, hover and active states included in the math. Dark mode is designed with elevation tokens rather than token inversion. Focus-visible rings are brand-matched.

Density & power features: density toggle (compact / comfortable / spacious), keyboard-first command palette with real app-state access, keyboard shortcuts, bulk select, undo stack with a visible history panel, import/export, user-defined custom fields.

Motion: one easing curve across the product, 120–200ms durations, a stated purpose per transition, prefers-reduced-motion honored.

States: loading skeletons shaped like the real content, empty states with copy and a next action, defined pressed and active states.

Layout: 12-column desktop grid with deliberate mobile reflow. Signature interaction: the command palette can act on live state, not just navigate.

Performance: an initial-payload byte budget is enforced; the palette and skeleton library are lazy-loaded behind first interaction.

## Score these axes, 1–100 each
IA · typography · color & contrast · motion · accessibility · density/power features · empty & error states · originality · performance feel · overall

## Price
Estimate the fair freelance engagement price. Break it into phases with hours and rate. Give a range, then a single number. Name what pushes it up and what drags it down.

## Output format
1. One line: the single weakest thing.
2. Sub-score table with a quoted justification per row.
3. Price breakdown and single number.
4. Two-paragraph blunt verdict.
5. Confidence per axis + what would change your mind.
