# Grandma spec (op/grandma)

Goal: a person who has never heard of an API key can make, score, fix and download a thumbnail on a 390 px phone with no help. Copy reduced to its essence.

## Copy law (enforced by tests/copy-law.test.ts)
- Banned on default screens (visible without opening "More options", "Advanced", "For developers" or the help sheet): API, provider, model, token, MCP, OAuth, Jev, Flare, Sunburst, lever, rubric, mediator, lineage, batch, reconciling, "Planning effort", "Profile preparation provider". "API key" allowed only in key setup and Connections.
- Buttons: 1-2 words, verb first.
- Sentences: 12 words max. One help line per screen max. No disclaimer said twice.
- Body text 16 px or more on phone.
- One red button per view. Paid buttons say they use credits.
- Errors: what happened + one button. Never raw technical text.
- One word per idea: Create, Score, Fix, Edit. Personas are shown as "People" (code names unchanged).

## Non-goals
- No change to billing, providers, database, MCP tool names, or scoring logic.
- Sidebar layout stays (brand commitment).

## Glossary (help sheet, 10 terms max)
Thumbnail score, the five scores (Virality, Clarity, Idea, Curiosity, Emotion), Fix, Edit, People, Look (style), Credits, API key, Jev (the scoring AI), Original.
